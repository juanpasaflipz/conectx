## 2. Conversion Funnel Stages

Each lead advances through these stages. A lead can only move forward when it meets the stated criteria. Leads can also exit to "not a fit" from any stage.

| Stage | Definition | Criteria to Advance | Owner Action |
|-------|-----------|--------------------|----|
| **sourced** | Lead identified from intelligence research. No contact attempted. | Contact path verified (account exists, DM open, number valid). | Verify contact info is still active before first touch. |
| **qualified** | Contact path verified and outreach script assigned. Ready to send. | Outreach message drafted and reviewed. | Customize script variant with group-specific details (name, known logistics activity). |
| **contacted** | First outreach message sent. | Message confirmed delivered (not just sent -- check for "seen" on IG, delivery receipt on WhatsApp). | Log date/time/channel of first contact. Screenshot the sent message. |
| **replied** | Lead responded to outreach. Any response counts, including "not interested." | Response received and categorized: positive interest, neutral/curious, negative, or redirect to someone else. | Respond within 2 hours max. Categorize the reply. If redirected, create a new lead for the referred contact. |
| **intro booked** | A 10-minute demo call or in-person meeting is scheduled. | Specific date, time, and format (video call, in-person, WhatsApp call) confirmed by both parties. | Send calendar confirmation or WhatsApp reminder. Prepare demo with their group name pre-loaded. |
| **pilot interested** | After the demo, the contact expressed willingness to try a match-day test. | Verbal or written confirmation of interest. Does NOT require a specific match date yet. | Ask: "Which upcoming match would work? How many people could join?" Begin identifying the specific match. |
| **test booked** | A specific match, date, number of testers (5-10), and logistics are confirmed. | Match date confirmed, minimum 5 participants committed, contact has agreed to coordinate their side. | Send pre-test checklist (install app, create squad, set meetup point). Confirm 48 hours before match. |
| **test completed** | The match-day test happened. Data collected. | Test executed. Post-test debrief done. Feedback captured. | Conduct 15-min debrief within 24 hours of match. Document what worked, what broke, squad size, mesh connections observed. |
| **not a fit** | Lead exited the pipeline. | Explicit rejection, sustained non-response after full sequence (14+ days, all channels), or disqualifying factor discovered (e.g., group is inactive, hostile, or does not attend matches). | Log the reason. Archive. Do not delete -- may re-approach for World Cup closer to June. |

## 5. Success Metrics & KPIs

### Primary Target

| Metric | Target | Deadline |
|--------|--------|----------|
| Match-day tests completed | 3 | May 11, 2026 |
| Unique penas with active pilot | 3 (one per team/category ideal: 1 home barra, 1 away group, 1 travel coordinator) | May 11, 2026 |

### Funnel KPIs

| Metric | Target | How to Measure |
|--------|--------|----------------|
| Response rate (contacted to replied) | 30-40% (3-4 of 10) | Replies received / outreach messages sent |
| Reply-to-intro conversion | 50% of replies | Demos scheduled / total replies |
| Intro-to-pilot conversion | 70% of intros | "Pilot interested" / demos conducted |
| Pilot-to-test conversion | 60% of interested | Tests booked / pilot interested |
| Overall funnel conversion | 10-15% (sourced to test completed) | Tests completed / leads sourced |
| Time to first reply | Under 5 days from first contact | Date of first reply - date of first outreach |
| Time to test booked | Under 21 days from first contact | Date of test booking - date of first outreach |

### Test Quality KPIs

| Metric | Target | Why It Matters |
|--------|--------|---------------|
| Squad size per test | 5-10 people | Below 5 does not stress-test mesh networking. Above 10 is bonus. |
| Mesh connections per test | 3+ simultaneous peer connections | Proves the P2P layer works in a real stadium environment. |
| Reagrouping success | Group successfully used meetup point to reconnect post-match | This is the core value proposition. If it does not work, nothing else matters. |
| Coordinator satisfaction (1-5) | 4+ | Would they do it again? Would they tell other groups? |
| Bug reports per test | Capture all, prioritize blockers | Feed directly to engineering for pre-World Cup fixes. |

### Feedback Loop Outputs

After each test, produce and share:

- **To Engineering:** Bug report with device models, Android/iOS versions, mesh connection logs, failure modes
- **To Content & Brand:** Coordinator quotes and testimonials (with permission) for marketing site and App Store listing
- **To Acquisition:** Lead source quality data -- which outreach channel and script variant produced the conversion
- **To Intelligence:** Full funnel data -- time-to-conversion, which group types convert fastest, optimal outreach timing

## 7. Tracker Update Protocol

This document is the single source of truth for the penas recruiting pipeline. Update it as follows:

- **After every outreach action:** Update the Status column in the lead tracker table and add a date note.
- **After every reply:** Log the reply type (positive/neutral/negative/redirect) in Notes. Update status.
- **After every demo:** Log outcome and next steps in Notes. Update status.
- **After every test:** Create a separate test report document and link it from Notes.
- **Weekly (Friday):** Review all lead statuses. Calculate funnel conversion rates. Identify blockers. Adjust next week's plan.

### Status Update Format

When updating a lead's status, append to the Notes column:

```
[DATE] STATUS_CHANGE: old_status -> new_status. Channel: [channel]. Details: [brief note].
```

Example:
```
[Apr 15] contacted via IG DM @barra_insurgencia. Script C sent.
[Apr 17] replied: "Si, les interesa. Manden mas info." Positive.
[Apr 18] intro booked: 10-min demo via WhatsApp call, Apr 20 at 7pm.
```
